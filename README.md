# 🛒 Bajar Lagbe — OOP-1 Project (Java)

Welcome to **Bajar Lagbe**, an **Object-Oriented Programming (OOP-1)** project developed in **Java** using **Notepad++**.  
This project demonstrates core **OOP principles** through a simple yet practical marketplace simulation.

---

## 📘 Overview

**Bajar Lagbe** (meaning *“Need Market”* in Bengali) is a Java-based console application that represents a **basic online market system**.  
Users can **browse items**, **add to cart**, and **simulate transactions** — all implemented using **Object-Oriented Programming concepts** such as:

- Classes & Objects  
- Inheritance  
- Encapsulation  
- Polymorphism  
- Abstraction  

This project was created as part of the **OOP-1 Course** at [AIUB](https://www.aiub.edu).

---

## 🧩 Key Features

- 🛍️ Add, view, and manage products.  
- 👤 Basic user account structure.  
- 💰 Simple transaction simulation.  
- ⚙️ Demonstrates all major OOP concepts in practice.  
- 🧱 Built entirely in **Java (JDK 17+)** using **Notepad++**.
